# CivicOS Logo Usage

Use these files for public submissions and future catalog listings:

- `civicos-mark-square.svg`
  - Best default for marketplaces and software catalogs.
  - Use this for the `Software Logo` field on `testing.govstack.global`.

- `civicos-logo-wordmark.svg`
  - Use when a wider header or document cover needs the full product name.

- `civicos-logo-submission.svg`
  - Use for decks, one-pagers, social previews, or proposal covers.

- `favicon.svg`
  - Website favicon only.

Rationale:

- The square mark is the safest long-term choice for external catalogs because it remains legible at small sizes.
- The mark matches the current CivicOS site branding and avoids mixing old purple assets with the new CMS-first public identity.
- Do not use GovStack's own branding as the primary software logo for CivicOS submissions.
- If you have to choose only one permanent public asset, choose `civicos-mark-square.svg`.
