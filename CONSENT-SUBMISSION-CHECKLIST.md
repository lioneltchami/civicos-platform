# CivicOS Consent Submission Checklist

CivicOS Consent Building Block submission.

- Live API docs: `https://api.civicosbb.ca/api/v1/consent/docs/`

## Tool description

Use this text in the tool description field:

`CivicOS is a Django 5.2 and Wagtail-based public-sector platform for governments, municipalities, and communities. This submission covers the GovStack Consent Building Block, with public documentation, a live consent-specific API schema, and a live backend runtime exposing config, service, and audit consent routes.`

## Software logo

Use the square mark for the GovStack form upload:

- Preferred upload asset: `civicos-site/public/civicos-mark-square.png`
- SVG alternative: `civicos-site/public/civicos-mark-square.svg`

reads more clearly in small thumbnail contexts.

in the submission form until it is fully connected and publicly resolving.
